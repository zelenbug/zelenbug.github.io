this is a Space Goofs fan project, based on the original flash game by Xilam (redrawn with more clothing options and recolorability). the original game is available on flashpoint
art & coding by zelenbug. not affiliated with xilam in any way

the color sliders actually modify an image with filters, and it can be difficult to get a color right, so try fiddling around with the sliders. even tweaking the hue on something with 0 brightness and 400 saturation (like if you want white clothes) will affect its brightness!
the pink box under a color just marks that its used by the selected clothing piece

you can click on the value of a color slider and type it in manually to set it more precisely as well. the color will update once you click away from the input box

the colors will reset if you switch to a different outfit piece for the layer, so be warned!!

some of the clothes are based on the original game, and go together in sets here as well, but it should be easier to mix them together now (with the ability to actually recolor clothes). here are all the original sets

Finds the closest color in the Spore editor palette (not in adventures) to the color you select. Not necessary if you have the Enhanced Color Picker mod, obviously.
Colors are arranged in a single row regardless of screen width, so if you use a phone in the portrait orientation, keep this in mind.
Closest matches might be a bit off (especially for green-cyans), so you might want to fiddle with your chosen color or pick what looks closer to you.



























































































Select the color you want to match. A green border around the color is an exact match, a yellow border is the closest match.

Both -blocks and -load creature loading commands below take the
following common optional parameters:
     * -pos <position:vector3> - position
     * -rot <angle:float>      - degrees of rotation around creature's z up vector
     * -scale <scale:float>    - creature instance scale
     * -lod <lod:int>          - force LOD level (0 = low, 3 = high)
     * -add                    - adds instead of replaces creature
     * -noMesh                 - doesn't create mesh
     * -noCache                - bypass the creatureanim cache

-blocks <creatureName:string> [-local] [common - see above]
   THE -blocks OPTION IS CURRENTLY BROKEN.
   Loads the named creature blocks file,
   from Data/Creatures/temp/creatures (or UserData/Creatures if -local)

-load [<creatureName:string>]
      [-instanceID <instanceID:number>]
      [-groupId <groupId:number> | -baby]
      [-typeId <typeId:number> | -flr | -cll]
      [common - see above]
   Loads a creature from the optional named crt file or the optional instanceId,
   with the optional groupId (defaults to Data, or UserData if -local)
   and typeId (defaults to crt type, or -flr, or -cll)
   If no name or id is given then a random creature is chosen from Data\Editors\Creatures

-creatureGroup [<creatureName:string>]
     [-instanceID <instanceID:number>]
     [-groupId <groupId:number> | -baby]
     [-typeId <typeId:number> | -flr | -cll]
     [-num <creatureQuantity:int>]
     [-center <groupCenter:vector3>]
     [-radius <boundingRadius:float>]
     [-same]
     [-typefilter]
   Works much like -load, but spawns multiple creatures placed randomly in a circle
   defined by the center and radius specified.
   The -same flag will force all creatures in the group to be the same creature
   (which is only really useful with random creature selection)
   The -typefilter parameter filters random creatures by the type (defaults to crt)

-remove [-creature <creatureNumber:int> | -all ]
   Removes a creature by number.  If no number removes current creature.

-selectCreature <creatureNumber:int>
   Makes the specified creature the selected creature .

-scale <scale:float>
   Sets the scale of the selected creature

The animation sequencing commands -anim, -animID and -wait below take the
following common optional parameters:
     * -start | -stop
         Start/stop the animation immediately, so you don't have to switch windows and hit
         the space bar like a monkey every time you want to play a goddamned animation.

     * -creature <creatureNumber:int> [<creatureNumber2:int>] | -all
         A creature (or all creatures) other than the current, to apply this anim to.
         If two creature numbers are given apply to the range covered by those numbers.

     * -add | -replace <slot:int> | -insert <slot:int>
         Determines where the animation will be added to the sequence.

     * -cond <conditionFOURCC:string>
         A condition code such as 'hit' or 'miss' which will apply to this animation.

-anim [<animationName:string>]
      [-playbackTime <playbackTime:float>] [-duration <duration:float>]
      [-instanceId <instanceId:number>]
      [-filename]
   Loads an animation on the current creature.  Invoke with 'spacebar' and stop with 'delete'
   Duration is the time the animation will take if play if allowed to play for its entirety.  
   PlaybackTime is the time we allow it to play in the sequencer.  instanceId is the rsrc key
   and overrides the name if both are present.  If -filename is passed, animationName is loaded
   from a discrete file, if not, it's loaded by the instance id of the hash of the last part.

-animID <animationID:uint32>
   Loads an animation by AnimList ID.  Invoke with 'spacebar' and stop with 'delete'
   If no name or id is given then a random animation is chosen from the AnimList
-wait <waitTime:float>
   Load as waiting period of waitTime seconds.

The following sequenced movement commands transition control immediate after starting,
so that you can move and play an animation at the same time.
To stop one before its natural finish you must interrupt with a new command of the same type..

-turn <turnTime:float> <turnAngleDeg:float>

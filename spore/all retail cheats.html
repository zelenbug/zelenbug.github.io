vanilla retail spore with all expansions. all transcribed manually so there could be typos

addDNA              : increases your DNA points
adventureLook       : Applies a stylized look to your adventure! If used while editing an adventure, it gets saved with the adventure. Set Graphics Effects to Medium or High
antiAliasGIF        : Antialias GIF captures and set a background color, Eg antialiasgif -bgColor (0.8, 0.3, 0.6)
blocksmode          : Toggle creature blocks mode.
capturePlanetGIF    : Captures a spinning GIF of the planet you are on and dumps to AnimatedAvatars directory
clear               : Clears the debug console
colladaexport       : Export the current creature as a collada file (.dae)
evoadvantage        : unlocks the ability to choose evolutionarily advantaged creatures from the Sporepedia when starting creature game
freeCam             : Toggles free camera mode.
freedom             : [on | off], toggles, disables (on) or re-enables (off) editor complexity limits. Creations that break the limits will not be pollinated!
help                : [<pattern:string>] [-full] Lists help for all cheats, or those that match <pattern>
highresTextureLevel : set or display the high res texture level
history             : [<items:int>] Lists the last n commands in the command history
killallhints        : Remove all hints from the game.
levels              : Level Cheats
moreMoney           : Increases your money in Civilization or Space
movie               : Movie cheat
option              : lists options or sets an option
pauseUIVisible      : sets or toggles whether the pause frame is drawn
prop                : Displays or modifies properties
quit                : Quit game
refillMotives       : Replenishes depleted health and other motives.
setConsequenceTrait : Sets the trait which will determine what super powers are available.
settime             : Sets the time of day at the avatar's position.
spaceCreate         : unlocks and recharges creation tools while playing in space.
styleFilter         : Applies a stylized look to Spore. Try these options -filmNoir, -oilPaint, -norainbows, -nextgen, -microscope
toggleCaptureUI     : toggles UI for image capture
toggleeditorbackground: toggle the background on/off in the editors (use with Ctrl-H for taking screen shots)
unlockSuperWeapons  : Unlocks all superweapons for your Civilization type.

adventureLook
-filmnoir
   Makes the adventure noisy and black and white
-eightbit
   Makes the adventure look like an old 8 bit game
-sixteenbit
   Makes the adventure look like an old 16 bit game
-watercolor
   Renders the adventure in watercolor
-norainbows
   Makes the adventure look dark and gloomy
-sepia
   Makes the adventure look like a sepia tone film
-none
   Return to normal

antiAliasGIF
-bgColor (r,g,b)
   Set background color, rgb range is 0-1
   Example: antialiasgif -bgColor (0.8, 0.3, 0.6)
   default is white

Spore locale tokens

These are encased between tildes ~like this~ and I think they're called tokens, according to the test locale and some other things. They're replaced with various values and other strings when the text is displayed in the game.
Tokens can also be used within another token to determine whether to use the correct singular or plural form of a word (for example, ~^p^badge_left^Alliance^Alliances~ uses ~badge-left~)
I found all of these by looking through all locale files with the regular expression ~.*?~

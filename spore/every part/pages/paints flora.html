Flora paints

Colors, used paints and descriptions come from the skinPaint_script~ files. Colors shown are as converted from floats in SporeModder FX, and might be ever so slightly off from their actual ingame color

You can view all flora paints applied to creatures (it's much easier to see here how they look like, in comparison to the paint icon) in the following posts from my blog: post 1, post 2, post 3, post 4, post 5, post 6
The really weird arrangement of paints (with random empty slots) is entirely accurate to the game
Another note: a color of (0, 0, 0) isn't actually pitch black, it just leaves the current base/coat/detail color on the creation intact (so most of the theme paints will not change any of the plant's colors, for example). Similarly, an unset paint (uses hash 0x00000000) doesn't change the respective paint slot

fe_skinpaint_floratheme_36.prop
key parent skinPaint_script~!TemplateSkinPaintTheme.prop
string16 description "fe_skinpaint_floratheme_36"
colorRGBs paintThemeColor1s
	(0, 0, 0)
	(0, 0, 0)
	(0, 0, 0)
end
keys paintThemePaints
	skinpaint_florabase_lumpy
	animations~
	animations~
end
fe_skinpaint_florabase_lumpy.prop
key parent skinPaint_script~!TemplateSkinPaintTheme.prop
string16 description "skinpaint_florabase_lumpy"
colorRGBs paintThemeColor1s
	(0, 0, 0)
	(0, 0, 0)
	(0, 0, 0)
end
keys paintThemePaints

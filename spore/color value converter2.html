Converts the colorRGB values found in the XML files for Spore creatures (or plants or cells), or colorRGB values in other files (such as consequence trait colors), into a visible color. It must be separated by commas!
Also the typed hex might be a little bit off, but the color actually shown here should be accurate to the game.

Example: 0.905882,0.333333,0.290189 or 0.314, 0.275, 0.804

#ffffff


This will convert three color and skinpaint values from a creation's XML (you can get them from PNGs in Kade's asset tool). Here you'll have to import it in this exact format (should have line breaks, and be in this order, but leading spaces don't matter): 
<skineffect1>0xa3163e4a</skineffect1>
    <skineffect2>0x52811f23</skineffect2>
    <skineffect3>0x64a50d94</skineffect3>
    <skineffectseed1>1234</skineffectseed1>
    <skineffectseed2>1234</skineffectseed2>
    <skineffectseed3>1234</skineffectseed3>
    <skincolor1>0.274509,0.443135,0.262743</skincolor1>
    <skincolor2>0.694117,0.513725,0.129411</skincolor2>
    <skincolor3>0.176470,0.282352,0.168625</skincolor3>

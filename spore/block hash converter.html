Converts (vanilla) hashes for parts, creation types, paints and some other hashes, found in their XML data. Use Spore Asset Tools to get XML data for any creation.





The creation type is the model type here 
<modeltype>0x9ea3031a</modeltype>

Paints are the skineffect1 through 3 values 
<skineffect1>0x71357e68</skineffect1>
<skineffect2>0xfaf08f43</skineffect2>
<skineffect3>0x103691ce</skineffect3>

The part name is specifically the second hash in its blockid 
<blockid>0x40626000, 0xd05c53a3</blockid>

Paints for individal parts are in the paintid value for a part 
<paintid>0xd49dbfac</paintid>

Hashes for morph handles are found for each part too, in weight channels 
<weight channel="0x9bfe8bf8">0.676777</weight>
